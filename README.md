## 关于 / About

长期从事搜索引擎、SEO/SEM 与 Web 分析相关工作。曾参与构建网易基于 **Lucene** 的搜索引擎（2001 年，国内最早采用 Lucene 的门户搜索引擎之一），并推动 Lucene 在搜房、BlogChina、GrassLand 等项目的应用。

自 2000 年代初开始写作技术博客，二十余年来坚持记录关于搜索引擎、开源软件、Web 开发与数据分析的实践笔记。
