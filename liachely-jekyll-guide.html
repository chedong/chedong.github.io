我的网站，我自己管

你的网站已经上线了！这本小手册教你怎么往里面加内容——写新文章、改页面、加项目，以及搞懂「push 一下就自动发布」是怎么回事。

先懂一件事

你的网站是怎么自动发布的

你只在一个地方工作：main 分支。剩下的交给机器。

✍️你在 main 分支改写文章、改页面，存好提交
→
🤖GitHub Actions 自动构建deploy.yml 用 Jekyll 把内容变成网页
→
🌐gh-pages 上线成品放到 gh-pages 分支，网站自动更新
两个分支分清楚：main 是你的「原料仓库」（你只碰这里）；gh-pages 是机器「做好的菜」（不要手动去碰它）。

第一步 · 最常用

1

写一篇新博客

所有文章放在 _posts 文件夹。在 GitHub 网页上新建文件时，把文件名写成 _posts/日期-标题.md，会自动进到文件夹里。

⚠️ 文件名必须是 年-月-日-标题.md，比如 2026-09-24-my-first-post.md。日期写错或漏掉，文章就不会发布，而且不会报错——这是新手最容易踩的坑。

写文章用的“小符号”（Markdown 速查表）

我想做就这样写
标题（最大）# 这是大标题
标题（小一点）## 这是二级标题
加粗**重点文字**
列表- 第一件事
链接[文字](https://链接)
图片![说明](/assets/img/图片.jpg)
引用> 一句想引用的话
图片要放进 assets/img/ 文件夹（上传图片时选这个目录），然后在文章里写上图的路径。

第二步

2

改页面、加项目

你的网站页面在 _pages 文件夹（比如 about-lia.md、photography.md、atlas.md），项目在 _projects（一个文件一个项目）。它们的开头都有一段「front matter」——就是上下各一行 --- 之间的信息，告诉网站这个页面叫什么、放在导航哪里。

  • 新建页面：在 _pages/ 新建 xxx.md，front matter 里写 permalink（网址路径）和 nav: true（要不要出现在顶部导航）
  • 新建项目：在 _projects/ 新建 1_名字.md，importance 数字越大越靠前，category 决定它归到哪一组
  • 正文里写图片时，用三行并排的写法（看现在项目的正文例子就能学会）

第三步

3

改网站的名字和设置

网站的「身份证」都在 _config.yml 里：标题、介绍、导航、评论、主题选项都在这里。想改名字，就在里面找 title: 那一行改掉。

  • 改了 _config.yml，同样 commit + push，等 1–2 分钟生效
  • 改设置前最好先复制一份备份，或者只改一行、确认没坏再加
  • 拿不准时，先在这本手册的「本地预览」里看效果再发布

进阶 · 可选

＋

先在电脑上预览（改完立刻看到）

不想每次改完都等网页刷新？可以在电脑上把网站「跑」起来。让爸爸帮你装好 Ruby 之后，在网站文件夹里打开终端：

  • 浏览器打开 http://localhost:4000 就能预览（只看网页，不占网上的）
  • 预览满意了，再 commit + push，网上才会更新
  • 如果页面样式没出来，可能是缺少前端依赖——让爸爸再跑一次 npm ci 就好

遇到问题看这里

常见问题

改了东西，网页怎么没变化？
① 刚 push 完要等 1–2 分钟（Actions 在后台工作）；② 去仓库的 Actions 页面看有没有变绿（绿=成功，红=有问题，点开看哪里红了）；③ 检查文章文件名是不是 年-月-日-标题.md 格式。
图片不显示怎么办？
检查两件事：图片真的上传到 assets/img/ 了吗？文章里写的路径和文件名完全一样吗（大小写也要一样）？
文件名可以用中文吗？
可以，但推荐用英文或拼音，避免出奇怪的问题。日期必须写成 2026-09-24 这种格式。
_posts 里那些 2015 年、2023 年的文章是什么？
那是模板自带的示例文章（教你怎么用各种功能），不是你的内容。以后可以一个个删掉，换成你自己写的。
不小心改了 gh-pages 分支怎么办？
别慌——它每次 push main 都会被自动重新生成。最保险的做法是平时根本不碰它；真的手滑了，让爸爸帮你在 Actions 里重新跑一次部署就行。

🗒️ 几条小规则（记住了就少踩坑）

  • 只在 main 分支改东西
  • 不手动碰 gh-pages 分支（那是机器管的地盘）
  • 文章命名 2026-09-24-标题.md，日期必须写对
  • 图片统一放 assets/img/
  • 大改动先在本地预览，满意再发布
  • 拿不准就小改一步、看效果，再走下一步
